Evaluación diagnóstica

1. ¿Qué entienden por sistema de información?

Es un conjunto de elementos que trabajan juntos para organizar información y ayudar a realizar actividades y tomar decisiones.

2. ¿Cuál es la diferencia entre un dato y una información?

Un dato es un valor aislado, mientras que la información tiene un significado. Por ejemplo, 200 es un dato; saber que se vendieron 200 productos en un día es información.

3. ¿Qué elementos forman parte de un sistema de información?

Sus elementos principales son el hardware, el software, los datos, las redes de comunicación y las personas que utilizan el sistema.

4. Mencionen dos sistemas de información que utilicen frecuentemente.

Redes sociales: las utilizamos para comunicarnos, compartir contenido y mantenernos en contacto con otras personas.

Aplicaciones bancarias: permiten consultar saldos, revisar movimientos y realizar transferencias desde el celular.

5. ¿Cuál es la función de una base de datos dentro de un sistema de información?

Sirve para guardar y organizar datos, de modo que podamos consultarlos o actualizarlos cuando sea necesario.

6. ¿Cómo ayudaría un sistema de información a una empresa que controla clientes, ventas e inventario?

Le permitiría organizar los datos de sus clientes, registrar las ventas y controlar los productos disponibles, ahorrando tiempo y reduciendo errores.

7. ¿Qué entienden por los siguientes términos?

ERP: sistema que ayuda a organizar los recursos y las actividades de una empresa.

CRM: herramienta para gestionar las relaciones con los clientes.

Aplicación web: programa que se utiliza desde un navegador.

Aplicación móvil: programa diseñado para celulares o tabletas.

Computación en la nube: permite guardar archivos y utilizar servicios por Internet.

API: permite que diferentes aplicaciones intercambien información.

UML: permite representar un sistema mediante diagramas.

Scrum: organiza el trabajo de un proyecto en periodos cortos.

Kanban: ayuda a organizar tareas y visualizar su avance.

8. ¿Qué entienden por requerimiento de un sistema de software?

Es una función o característica que debe tener un programa para satisfacer las necesidades de sus usuarios.

9. ¿Para qué sirve realizar diagramas o modelos antes de desarrollar un sistema?

Sirven para organizar las ideas, comprender cómo funcionará el sistema y detectar posibles errores antes de programarlo.

10. ¿Qué metodología, enfoque o forma de trabajo para desarrollar software conocen?

Conocemos el ciclo de vida del software, que incluye etapas como la planificación, el diseño, el desarrollo, las pruebas y el mantenimiento.
